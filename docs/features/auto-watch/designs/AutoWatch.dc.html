Auto watch: each repository says what starts

The app side of the auto watch PRD (R43, with R27, R31, R33 and R37): the repository settings, the queue, the auto and update badges, merge when ready, and the new notifications.

1. Repository settings

A panel icon in the repository header opens the settings, docked like the watch settings (R43). Watches that auto start carry an auto badge; Dependabot updates beyond the limit wait in the list with a queued badge and their place (R21, R23).
